# FlowX Landing Page

Marketing landing page for FlowX, focused on cross-border money transfer messaging, product story, and conversion sections.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- GSAP / Motion

## Run Locally

Prerequisite: Node.js 18+

1. Install dependencies:
   `npm install`
2. Start development server:
   `npm run dev`
3. Build for production:
   `npm run build`
4. Preview production build:
   `npm run preview`
